=== CYBER BLADE PWA FILES (GITHUB UPLOAD GUIDE) ===

1. In sabhi files ko apne GitHub Repository me upload karna hai:
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png

2. Upload karne ka aasan tarika:
   - Apne GitHub repository par jaye (jahan game host hai).
   - 'Add file' -> 'Upload files' par click karein.
   - In sabhi 5 files ko drag & drop karein.
   - Niche 'Commit changes' par click karein.

3. 1 minute ruk kar https://www.pwabuilder.com par apna URL dalein:
   - Ab sabhi checks Green ho jayenge!
   - 'Package for Stores' button unlock ho jayega!
